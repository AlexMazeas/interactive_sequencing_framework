# Interactive SE–BCT Sequencing Framework

This interactive web-based resource enables users to explore the proposed sequencing of **self-enactable behavior change techniques (SE-BCTs)** described by **Mazéas and Ntoumanis (2026)**.

Users can navigate clusters and groups of SE-BCTs, examine when different groups are proposed to be most relevant across the behavior-change process, and view individual SE-BCTs together with their mode of enactment and, where applicable, prerequisite techniques.

## Explore the interactive framework

**Interactive website:** https://alexmazeas.github.io/interactive_sequencing_framework/
